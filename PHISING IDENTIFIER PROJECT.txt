9. ADD ML-

app cant rely on manually written mails, what if the user is actually from any org but still is pretending to be real

The process will be:
1. Obtain a suitable labelled dataset.
2. Clean and prepare the email text.
3. Convert the text into numerical features using TF-IDF.
4. Train a classification model.
5. Test it on emails it hasn't seen during training.
6. Measure precision, recall and F1-score.
7. Compare the model's results with our rule-based detector.
